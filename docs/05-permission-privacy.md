# 05｜可见范围、匿名与权限规格（最高优先级）

> 本章条目一旦违反即为 P0 缺陷，必须停止相关能力并修复。UI 好看与否可以讨论，本章不可让步。

## 5.1 两个独立维度

```text
visibility:   public | club | private     // 谁能看见
identityMode: named  | anonymous          // 以什么身份出现
```

- `public`：在 `capabilities.publicScope` 开启后，任何访问本小程序的人可能看到。
  **不等于**自动同步朋友圈或被搜索引擎收录。
- `club`：仅当前**有效**社团成员可访问；成员资格撤销后立即失去历史帖访问权。
- `private`：仅本人在个人空间可见；不进入内容流、话题、文集、搜索、互动与通知。
- `anonymous`：对其他成员隐藏昵称、头像与可跳转主页。**不是**无法追责，
  **不是**技术上的绝对匿名。UI 文案必须体现这一点。

首版不支持"指定某几人可见"。

## 5.2 权限矩阵（服务端实现，前端按返回字段渲染）

| 能力/对象 | 访客 | 有效社员 | 内容作者 | 普通管理员 | 受限安全处理角色 |
|---|---|---|---|---|---|
| 已审核公开帖 | 可读 | 可读/互动 | 可管理自己的 | 按流程治理 | 按授权处理 |
| 已审核社内帖 | 不可读 | 可读/互动 | 可管理自己的 | 职责内可读 | 必要范围可读 |
| 仅自己正文 | 不可读 | 不可读他人 | 可读/改/删自己的 | 默认不可读 | 仅在明确必要、受控流程下处理 |
| 待审/退回内容 | 不可读 | 不可读他人 | 可看状态与理由 | 分配队列可见 | 必要范围可处理 |
| 匿名账号关联 | 不可见 | 不可见 | 不通过公开接口返回 | 默认不可见 | 受控授权 + 理由 + 审计 |
| 举报者身份 | 不可见 | 不可见 | 不因被举报可见 | 最小职责处理 | 必要范围处理 |
| 改变帖子范围 | 无 | 无权改他人 | 首版只允许缩小 | 不可代作者扩大 | 隐藏治理 ≠ 公开内容 |
| 收录文集 | 无 | 可自愿申请 | 可授权/撤回 | 有编辑权且范围匹配才可收录 | 不自动获得版权处置权 |

## 5.3 匿名实现红线

1. 同一帖子线程内，同一参与者生成**稳定随机别名**；作者回复带"作者"标志。
2. 不同帖子之间**不提供**可串联的匿名主页或稳定标识。
3. 真实映射放受限存储，**禁止**出现在：
   - Post/Comment 的任何公开响应字段
   - 图片文件名、对象存储路径、EXIF、视频元数据
   - 头像地址、点赞名单、导出文件、通知文案、日志、埋点
4. 站内搜索真实昵称**不得**返回其匿名帖。
5. 屏蔽匿名作者可由服务端内部处理，但**不得**向用户返回"这两位匿名者是同一人"。
6. 发布前预览必须提示：具体经历、地名、班级、画面、文风仍可能被认出。
   **禁止**出现"绝不会被认出""完全匿名"字样。

## 5.4 范围变更与成员变动

- 允许：`public → club`、`club → private`、`public → private`。
- **禁止**：`private/club → public`（需新建内容，重新确认身份、来源与授权，不继承原评论与点赞）。
- 缩小范围必须二次确认，并告知"已有截图无法追回"。
- 退社/被移除：立即撤销社内读写；作者仍可通过受限的"我的数据/删除申请"管理历史内容。
- 社团解散/换届/管理员离任：权限回收 + 责任交接；**禁止**一键公开社内帖。

## 5.5 所有入口同一条规则（越权验收用例）

| 入口 | 不允许出现的漏洞 | 验收方式 |
|---|---|---|
| 信息流/话题/主页 | 私密或匿名历史被夹带在列表或总数中 | 三种账号查询同一游标，比较允许集合 |
| 搜索 | 正文隐藏但摘要/高亮泄露 | 搜索私密帖唯一词，数量与结果均不泄露 |
| 收藏 | 原文收回后仍显示旧封面/摘要 | 缩小范围后用另一账号刷新收藏 |
| 分享 | 社内卡片泄露原文或封面 | 社内统一中性卡片；目标页重新鉴权 |
| 通知 | 旧通知残留敏感内容 | 中性文案 + 打开时复核权限 |
| 媒体 | 拿到 URL 绕过帖子权限 | 私有桶 + 授权访问；无授权直取应拒绝 |
| 缓存 | 前一账号数据留给后一账号 | 退出/切号/成员撤销后按账号前缀清理 |
| 管理/导出 | 运营入口"一键看所有私密" | 普通管理角色越权测试 + 最小导出集合 |

> 短时签名链接只缩短泄露窗口，**不等于**即时撤权。需选择可校验权限版本的代理/边缘鉴权方案；
> 视频分片同样适用。已下载文件无法强制收回，验收文档必须写明缓存失效时间与残留风险。

## 5.6 前端硬性检查清单（Code Review 必过项）

- [ ] 组件层没有任何权限判断代码（搜 `isOwner`、`role ===`、`visibility ===` 的分支须在页面/服务端字段驱动）。
- [ ] 详情页不复用列表数据渲染正文，必须按 `id` 重新请求。
- [ ] 匿名帖不渲染 `userId`、不提供作者主页跳转，头像点击只弹匿名说明。
- [ ] 范围选择器在 `capabilities.publicScope = false` 时不显示 `public`，且提交也不带该值。
- [ ] 任何"仅自己"内容页面不渲染共鸣/评论/收藏/分享入口。
- [ ] 待审内容只在本人视图可见，且带明确"等待审核"标签，不混入已发布列表。
- [ ] 退出登录 / `membership_invalid` 时按 `hg:{userId}:` 前缀清理 storage，并重置内存态。
- [ ] 通知列表渲染前先校验 `target` 可访问性，不可访问显示中性占位。
- [ ] 分享菜单：`private` 关闭；`club` 使用中性文案。
- [ ] 埋点 payload 里不含正文、草稿、alias、搜索原词长期留存。

## 5.7 隐私文案基线（可直接使用）

| 场景 | 文案 |
|---|---|
| 范围选择-社内 | 仅社内可见 · 只有当前有效成员能看到 |
| 范围选择-公开 | 公开可见 · 任何打开本小程序的人都可能看到 |
| 范围选择-仅自己 | 只有自己可见 · 不进入社区流、话题、搜索与互动 |
| 匿名开关说明 | 以树洞身份发布：其他人看不到你的昵称与头像。这不是绝对匿名——具体经历、地名、画面与文风仍可能让人猜到你。 |
| 发布预览 | 你将以「{身份}」发布，{范围文案}。提交后会先进入审核。 |
| 待审核结果 | 已收到，等待审核。通过后会在你设定的范围内展示。 |
| 缩小范围确认 | 改为「{目标范围}」后，原受众将无法再看到这条内容。已经保存的截图无法追回。 |
| 删除确认 | 删除后无法恢复，相关回应也会一并停止展示。 |
| 无权访问 | 这条内容当前不可访问。 |
| 清缓存说明 | 仅清理本机缓存，不会删除云端账号与内容。 |
