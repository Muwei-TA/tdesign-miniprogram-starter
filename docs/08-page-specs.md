## P01｜树洞首页 ✅

**目标**：快速读到新的表达，并知道自己也可以参与。
**入口**：启动、Tab「树洞」、发布结果返回。

**布局（自上而下）**

1. `hg-nav`（transparent，无返回）：左侧消息图标（未读时 `@hg-clay` 小点），
   右侧避开小程序系统胶囊，不放页面操作。
2. 欢迎区：`@hg-fs-display` serif 一行主句（"留一盏灯，给每一种表达。"）+ 24rpx 说明。
3. 无放大镜的搜索条（点击进入 P11，不在本页输入）。
4. 本周共写卡：`@hg-green-mist` 底、eyebrow「THIS WEEK」、话题标题、一行说明、右上箭头。
5. 筛选 chip 行（横滑）：全部 / 生活 / 灵感 / 文章 / 视频 / 待回应。
6. 内容流：`post-card` 单列，默认按最近发布排序。
7. FAB「写一笔」。

**交互与去向**

| 操作 | 去向 |
|---|---|
| 卡片正文 | P05（`from=feed`） |
| 图片 | `wx.previewImage` |
| 视频 | 详情内播放（列表点击进入 P05 后播放） |
| 话题 chip | P03 |
| 署名作者 | P18；匿名作者 → 匿名说明弹层 |
| 共鸣/收藏 | 当前页乐观更新，失败回滚 + toast |
| 消息 | P08 |
| 搜索 | P11 |
| 社徽 | P14 |
| 写一笔 | P04 |

**状态与验收**

- 访客只看到公开且已通过审核的内容；社内内容不出现在列表与计数中。
- 空态："这里还很安静 / 写下第一笔"，**不伪造活跃数据**。
- 加载失败：保留已加载数据 + 顶部"未更新"+ 重试。
- 分页用稳定游标，新帖插入不产生重复项。
- "待回应"筛选定义：已发布 + 允许评论 + 当前用户可访问 + 尚未收到有效文字回应。
- 列表**不得**返回仅自己、待审、已隐藏内容。

**实现要点**：筛选切换重置游标；`onShow` 订阅 `post-changed/post-created` 做局部更新，
不整页重拉；滚动位置保留。

## P02｜话题广场 ✅

**目标**：降低"不知道说什么"的门槛。

**布局**：`hg-nav`（标题"话题"）→ 分类 chip（全部/生活/阅读/灵感/倾诉/活动/共玩）→
`topic-card` 列表（图标方块 + 标题 + 一行说明 + 参与情况）→ 底部"发起一个话题"次按钮。

**交互**：卡片 → P03；发起话题 → 弹层（名称 ≤40 字、描述 ≤200 字、分类）→ 提交后 `pending`；
输入已存在同名话题时提示"已有相同话题，去参与"，**不创建重复项**。

**验收**

- 访客看不到社内话题的成员、参与计数与讨论摘要。
- 无话题时提示了解社团或申请加入。
- 待审核话题只在提交者视图与管理台出现，且带"待审核"标签。
- 新话题一律社内话题。

## P03｜话题详情 ⬜（T-07）

**布局**：`topic-banner`（`@hg-green-mist` 底，53px 图标方块、26px serif 标题、引导语、
规则说明一行）→ 关注按钮（右上或 banner 内）→ 区块标题"大家写下的"→ `post-card` 列表 →
底部固定"我也写一笔"主按钮。

**交互**

| 操作 | 去向 |
|---|---|
| 我也写一笔 | P04，预填 `topicId`；**不替用户选择匿名或范围** |
| 参与内容 | P05（`from=topic`） |
| 关注 | 加入「我的话题」（P10 `tab=topics`） |
| 返回 | 保留 P02 列表位置 |

**验收**

- `archived` 话题：可读，不再接受新投稿（主按钮置灰 + 说明）。
- 无参与内容：空态邀请写第一句。
- 关联帖仍按自身 `visibility` 过滤；`private` 帖不得关联话题。
- 话题归档/删除不删除作者原帖，原帖处显示"话题已归档"。
- 关注**不等于**订阅强提醒，首版不发站外通知，说明文案需体现。

## P04｜写一笔 / 统一发布器 ✅（媒体与上传链路待接）

**目标**：写之前不被表单劝退，发之前清楚自己暴露了什么。
**入口**：P01 FAB、P03 参与、P07 文集投稿、P10 草稿续写。

**布局**

1. `hg-nav`：返回 + 标题"写一笔" + 右侧"预览"文本按钮。
2. 分段控件：碎片 / 文章。
3. 文章模式：标题输入（serif 24px，无边框，下边线）。
4. 正文 `textarea`：碎片 15px sans / 文章 serif；最小高 370rpx；底部右侧字数统计。
5. 附件工具行：图片 / 视频 / 话题（视频受 `capabilities.video` 控制）。
6. 已选附件网格（176rpx 方块，右上角移除按钮）。
7. 表单行区块（`form-row`）：
   - 谁可以看见 → `scope-picker`，默认「仅社内可见」
   - 以树洞身份发布 → `switch`
   - 允许回应 → `switch`（默认开）
   - 关联话题 → 选择/清除
8. 发布预览条（`@hg-green-soft` 底）：一句话汇总身份 + 范围 + 审核提示。
9. 底部按钮组：存草稿（次） / 发布（主）。

**交互与去向**

- 选图/视频：先说明用途 → 系统选择器 → 校验数量/大小/时长 → 生成预览 → 可单独移除。
- 图片与视频互斥：已选其一时另一入口禁用并给出说明。
- 碎片 → 文章：内容不丢；文章 → 碎片：超 2000 字先提示，**不截断**。
- 预览：弹层展示正文、附件、身份、范围，二次确认后提交。
- 提交成功 → `redirectTo` P17。
- 自动草稿：输入停止 1.5s 或页面隐藏时保存；离开时弹三选项确认。

**验收**

- 无内容不能提交；纯图/纯视频允许；文章标题必填。
- 上传中禁止重复提交；单附件失败可重试；取消不留公开半成品。
- 网络中断保留草稿；提交带 `Idempotency-Key`，服务端幂等防重。
- 「仅自己」选择后：清除话题关联并隐藏"允许回应"（社区互动不适用）。
- 文案不得承诺"仅自己"是运营方绝对无法接触的加密保险箱。
- 视频能力关闭时入口置灰 + "视频功能暂未开放"。

## P05｜内容详情 / 长文阅读 ✅（评论区待接 T-06）

**两种形态**

*碎片详情*：作者行（头像 + 身份标签 + 时间 + 范围标识 + 更多）→ 正文 16px/2.0 →
媒体（图片 540rpx / 视频）→ 话题 chip → 操作条（共鸣/评论/收藏/分享）→ 评论区。

*长文阅读*：顶部 2rpx 阅读进度条 → kicker（分类 · 日期）→ 29px serif 标题 → 作者行 →
阅读工具条（字号 A- / A / A+ · 夜间）→ `article-text`（17px serif，行高 2.15，段距 1.25em）→
文末装饰"· · ·" → 媒体 → 操作条 → 评论区。

**交互与去向**

| 操作 | 结果 |
|---|---|
| 共鸣 / 收藏 | 停留当前页，乐观更新 |
| 评论 / 回复 | 提交后显示"等待审核"，通过后展示 |
| 更多 | 举报 / 减少看到某作者；本人内容额外：缩小范围、删除 |
| 署名头像 | P18 |
| 匿名头像 | 匿名说明弹层（不跳转） |
| 返回 | 回到来源页，不强制回首页 |

**验收**

- 无权/已隐藏/已删除：统一不可访问态，**不泄露标题**。
- 待审内容仅本人可预览，带"等待审核"标签。
- 关闭评论：不接受新评论并说明原因。
- `private`：不显示任何社区互动。
- 匿名作者在本帖中的回复不得露出真实昵称，且带"作者"标记。
- 举报提交后给回执文案，**不等于**认定违规。
- 夜间模式与字号设置持久化（账号作用域），返回列表不影响其他页面。

## P06｜社团文集 ✅

**布局**：`hg-nav`（标题"文集"）→ 顶部导语（serif 24px + 说明）→
`collection-cover` 两列网格 → 底部"写一篇文章"入口。

**验收**

- 公开/社内标识清晰（封面必带 `visibility-badge`）。
- 访客不看到社内文集的敏感目录与数量。
- 空文集可显示征集引导，**不假造已收录作品**。
- 未完成授权的文章不出现在目录。
- 收录规则不使用点赞排名，UI 不展示排行。

## P07｜文集目录 / 投稿入口 ⬜（T-08）

**布局**：hero（横向：书脊封面 133×182 + 文集名 + 编辑导语 + 范围标识）→
编辑说明段 → 目录列表（序号 Georgia serif + 标题 16px serif + 作者/日期）→
底部"向本期投稿"主按钮 + 投稿说明。

**交互**

- 目录条目 → P05（`from=collection`），返回回到本目录。
- 投稿 → P04 文章模式，携带 `collectionId`，页面顶部提示文集范围，
  且**必须单独勾选授权复选框**才能提交。

**验收**

- 文章状态实时读取，**不做正文快照**绕过原文权限。
- 公开文集不接收社内原帖；编辑不能自动扩大范围，需作者另建符合受众的新文章。
- 作者缩小范围或撤回授权 → 目录同步移除；提示"已缓存截图无法收回"。
- 未入选给温和告知，明确"不等于作品违规"。
- 内容通过安全审核后才进入文集编辑审核；**安全合格 ≠ 被选中**。

## P08｜消息中心 ✅

**布局**：`hg-nav`（返回 + "消息" + 右侧"全部已读"）→ 分段控件（回应 / 系统）→
`note-row` 列表（圆形图标 + 标题 + 一行摘要 + 时间 + 未读点）。

**规则**

- 两类：回应（评论/回复）与系统（入社、审核、举报处理、文集结果、公告）。
- 共鸣**聚合**展示（如"3 人对你的《…》表示共鸣"），避免连点刷屏。
- 首版**没有私信会话**（必须删除模板 chat 链路）。

**验收**

- 通知文案不含匿名映射、私密正文、原始图片。
- 入社失效后，旧通知不能读到社内内容（渲染前复核权限，失效显示中性占位）。
- 无消息不制造红点；失败可重试，不假装已同步。
- 订阅消息为后续可选通道，需用户明确授权，文案不承诺必达。

## P09｜我的 ✅

**布局**：hero（`@hg-green-mist`，57px 头像 + 昵称 24px serif + 身份说明）→
统计行（我的记录 / 收藏 / 关注话题，数字 Georgia serif）→
内容分类菜单（已发布、待审核/退回、草稿、私密手记、收藏、关注话题）→
社团区（社团名片、社区约定、社团管理[仅授权可见]）→ 设置。

**验收**

- 统计仅面向自己；**不得**把私密记录数当公开徽章。
- 访客态：显示介绍 + 申请加入，不显示上一账号历史内容。
- 退出账号：清账号作用域缓存 + 切访客态。
- 管理入口仅在服务端返回管理角色时出现；接口仍需鉴权。
- 信息编辑不强制填写生日、院系、学号。

## P10｜我的内容列表 ⬜（T-09）

同一页面按 `tab` 参数切换六种视图，**不新建六套逻辑**：

| tab | 内容 | 条目去向 |
|---|---|---|
| `published` | 已发布 | P05 |
| `pending` | 待审核 / 退回 | P05（本人预览）；退回 → 查看理由 → 重新编辑 |
| `draft` | 草稿 | P04 恢复 |
| `private` | 私密手记 | P05（仅本人，无互动） |
| `bookmark` | 收藏 | P05；失效项显示占位并可移除 |
| `topics` | 关注话题 | P03 |

**验收**

- 待审不混入已发布列表。
- 原文被隐藏后的收藏显示占位，**不留摘要**。
- 自己的已隐藏内容提供处理原因与申诉入口，不"凭空消失"。
- 收藏数与列表失效项口径一致。
- 草稿删除与内容删除分别处理，均有二次确认或可撤销反馈。

## P11｜站内搜索 ⬜（T-10）

**布局**：搜索栏（自动聚焦）→ 未输入时显示推荐词 chip + 最近搜索 →
输入后分段（内容 / 话题）→ 结果列表（`post-card` compact / `topic-card`）。

**交互**：输入防抖 300ms；清空恢复推荐词；结果点击进入 P05 / P03。

**验收**

- 服务端**先鉴权再排序分页**；摘要不得泄露隐藏正文。
- 匿名帖不因搜索真实作者昵称被检出。
- 仅自己内容只在 P10 私密列表内另查，不进站内搜索。
- 慢请求不覆盖新查询（按请求序号丢弃过期响应）。
- 失败重试不清空输入；无结果提示换词。
- 推荐词由编辑维护，**不从私密内容自动抽取**；搜索日志不留正文草稿。

## P12｜加入文学社 ⬜（T-11）

**布局**：社徽（76px 圆环）→ 标题"加入黑光文学社"→ 说明段 →
表单（昵称、邀请码）→ 社区约定链接 + 隐私告知复选 → 提交主按钮 → 状态区。

**交互**：阅读规则 → P16 并返回**保留输入**；提交 → `pending`；
管理员批准 → 成员生效 → 回到原场景（`from`）或 P01；被拒绝显示理由 + 重新联系入口。

**验收**

- 错误码/过期码/重复申请/待审/通过/拒绝六种状态文案明确。
- 正式版限制猜码频率（前端做基础节流，后端限频）。
- 生产版通过微信登录取得后端会话；**不在前端硬编码邀请凭证**。
- 用户拒绝可选授权时，仍可阅读允许公开的介绍。
- 最小数据采集：不索取手机号、位置、学号、通讯录。

## P13｜设置与隐私 ⬜（T-12）

**分组**

1. 内容与隐私：默认可见范围说明、匿名边界说明、社区约定（→ P16）。
2. 阅读：长文字号、夜间阅读默认。
3. 数据：清除本机缓存、导出我的内容（受 `capabilities.export`）。
4. 账号：联系运营者、注销账号（危险色）。
5. 关于：版本、交付边界说明。

**验收**

- 清缓存 ≠ 删除云端账号，文案必须说明。
- 导出：确认本人身份后异步任务，完成后通知。
- 注销：风险告知 → 二次确认 → 服务端清理或依法必要保留 → 结果通知；
  失败显示"处理中/待处理"，**不显示虚假完成**。
- 撤回文集授权是独立入口，不以注销作为唯一撤回方式。
- 页面需展示运营主体、联系方式、处理目的、保存期限、权利申请渠道（文本由运营填写）。

## P14｜社团名片 / 轻公告 ⬜（T-11）

**布局**：hero（社徽 + 社团名 + 一句介绍）→ 介绍段 → 当前公告/活动卡（复用 `post-card` 的 `event` 类型：
日期、地点、"感兴趣"按钮）→ 社区约定入口 → 加入/已加入状态区。

**验收**

- 访客不见成员名册、联系方式与社内活动敏感细节。
- 活动结束显示"已结束"；无公告时正常显示介绍。
- "感兴趣"只是意向，可取消；**不做签到、付费、锁名额**。
- 社团信息更改由授权人员通过管理接口完成，前端不提供编辑入口（首版）。

---

## P15｜社团管理台 ⬜（T-13）

**布局**：`hg-nav`（"社团管理"）→ 队列分段（内容 / 话题 / 入社 / 举报 / 文集）→
`moderation-item` 列表（来源、状态、摘要、时间）→ 动作按钮组 →
处理理由弹层（必填理由才可提交退回/隐藏）。

**验收**

- 入口仅对授权人员出现在 P09；**深链与接口同样鉴权**（分包不是安全边界）。
- 内容审核需能查看对应媒体与风险结果，不仅看文字摘要。
- 并发处理用 `expectedVersion` 版本锁，重复操作幂等。
- **不能用审核按钮更改作者的可见范围**。
- 普通管理员不可看私密手记与匿名映射；举报记录不公开举报人。
- 所有管理操作产生审计日志（服务端）。
- 成员移除、禁言、角色调整、公告配置属生产管理模块，首版页面不提供全量表单。

## P16｜社区约定 ⬜（T-12）

**内容结构**：来源说明（原有三项约定：不涉黄、不涉政、不人身攻击）→
新增条目（不骚扰、不披露他人隐私、尊重作品来源、举报与申诉、匿名边界、公开范围解释）→
版本号与变更摘要 → 返回原场景按钮。

**验收**

- 规则与隐私告知分层清楚：同意文明讨论 ≠ 同意无限制使用个人内容。
- **不得**混淆"社团约定 / 平台要求 / 法律义务"三层。
- 不建立公开"曝光名单"；争议走举报流程。
- 对情绪表达不做机械封禁或自动诊断；明确危险时按运营指引引导线下支持，
  并说明本产品不替代专业服务。

## P17｜发布结果 ⬜（T-05）

**三种状态**

| `state` | 标题 | 说明 | 主操作 |
|---|---|---|---|
| `private_saved` | 先留给自己 | 这条内容只有你能看到，不会进入社区流。 | 查看私密手记 / 回树洞 |
| `pending` | 已收到，等待审核 | 通过后会在「{范围}」以「{身份}」展示。 | 查看我的发布 / 回树洞 |
| `published` | 已展示 | 现在在「{范围}」可以看到它了。 | 查看内容 / 回树洞 |

**布局**：70px 圆形对勾（`#E5EEDA/#688558`）→ 24px serif 标题 → 说明 →
身份与范围摘要条 → 主/次按钮 → "继续写一笔"文本按钮（新建默认社内）。

**验收**

- 基于**真实服务端结果**呈现，禁止写"发布成功，大家都能看到"。
- 幂等键相同只产生一条 Post。
- 上传失败或结果未知 → 回到可恢复的提交页查询状态，**不盲目重发**。
- 审核结果延迟由 P08 与 P10 承接。
- 本页用 `redirectTo` 进入，返回栈不残留编辑器。

## P18｜社员主页 ⬜（T-14）

**布局**：hero（头像 57px + 昵称 + 加入时间/身份一行）→ 统计（仅可见作品数）→
作品列表（`post-card` compact）。

**验收**

- 只展示署名且当前访问者有权阅读的作品。
- **不展示**匿名历史、私密统计、联系方式、MBTI、真实学校身份。
- 作品计数按当前访问者可见集合计算，不暴露社内发帖量。
- 无私信、无关注/粉丝按钮。
- 匿名身份不跳到本页；客户端拼 `userId` 也不能取得隐藏历史（服务端保证）。
- 被移除成员/访客/无可见作品：显示对应空态。
- 自己的管理历史走 P09/P10，与对外主页查询接口分离。
