# 01｜产品范围与关键决策

> 依据：`product-plan.md` 01–05、13 章。本文件是所有开发任务的范围边界，任何"顺手多做一点"都要先改本文件。

## 1.1 一句话定义

为**一个大学文学社**提供的"低压力表达 + 作品留存"空间：成员可发一句话、一张照片、一段未成形的故事、
一篇文章或一段短视频；**先决定谁能看，再决定用什么身份发**；他人可回应、共鸣、收藏；
作者明确授权后，文章可进入社团文集。

## 1.2 四项不可动摇的产品决策

| 决策 | 实现约束 |
|---|---|
| 生活与文学共存 | 单一 `Post` 模型 + 类型筛选（生活/灵感/文章/视频/活动），**不拆板块** |
| 可见范围与匿名身份是两个独立维度 | `visibility` 与 `identityMode` 分别为独立控件，UI 不可合并成一个开关 |
| 表达必须得到回应 | 评论/回复/共鸣/站内通知/"待回应"筛选为 P0，不做热榜与粉丝体系 |
| 留存不等于替作者公开 | 文集收录需**单独授权**（`Consent`），范围取交集，作者可撤回 |

## 1.3 P0 范围（首版必须完整闭环）

| 模块 | 首版边界 | 对应页面 |
|---|---|---|
| 加入与成员资格 | 微信登录、自选昵称、邀请申请、人工确认、退出/移除后权限回收 | P12 / P15 |
| 内容发布 | 碎片/文章统一编辑器；纯文本、图片组或单视频；可选话题；草稿 | P04 / P17 |
| 范围与身份 | 公开/社内/仅自己（默认社内）；匿名独立开关；公开能力受开关控制 | P04 / P05 |
| 互动与找回 | 共鸣、收藏、评论、单层回复、站内通知、权限内搜索 | P05 / P08 / P11 |
| 话题 | 列表、详情、关注、社员提交话题、管理员通过/归档；每帖最多 1 主话题 | P02 / P03 |
| 文集 | 少量人工文集、目录、人工收录、作者授权/撤回 | P06 / P07 |
| 管理与安全 | 内容/话题/入社/举报/文集申请五队列，处理理由、可申诉、可审计 | P15 |
| 个人空间 | 发布/待审/草稿/私密/收藏/关注话题、隐私说明、账号权利入口 | P09 / P10 / P13 |

## 1.4 明确不做（首版）

私信聊天（**必须删除模板 chat 相关链路**）、热度排行榜、关注/粉丝、积分签到、打赏付费、广告、
电商、AI 代写、实时协同、跨校多租户、无限嵌套评论、富文本图文混排编辑器、复杂活动报名系统、
指定成员可见（`P1` 再评估）。

## 1.5 产品限制值（前端校验 + 后端复核）

| 对象 | 限制 | 前端处理 |
|---|---|---|
| 碎片正文 | ≤ 2000 字，标题可空 | 超限提示切换文章模式，**不截断内容** |
| 文章 | 标题 ≤ 60 字（必填），正文 ≤ 20000 字 | 超限阻止提交，光标定位与计数提示 |
| 图片 | 单帖 ≤ 9 张，单张 ≤ 10MB | 选择时校验数量/大小，失败可单张重试 |
| 视频 | 单帖 1 个，≤ 60s，源文件 ≤ 30MB | 超限拒绝并说明原因；能力关闭时入口置灰说明 |
| 媒体组合 | 图片组 **或** 视频，二选一；允许纯媒体 | 已选图片时视频入口禁用，反之同理 |
| 评论 | ≤ 1000 字，一级评论 + 定向回复 | 回复对象必须属于同帖 |
| 话题 | 名称 ≤ 40 字，描述 ≤ 200 字 | 提交后进入待审核 |

## 1.6 功能开关（服务端下发，前端只读）

```text
capabilities: {
  publicScope: boolean,   // 公开可见范围是否可选。关闭时：范围选择器隐藏 public 项并说明
  video:       boolean,   // 视频链路是否验收通过。关闭时：视频入口置灰 + "暂未开放"说明
  anthology:   boolean,   // 文集投稿是否开放
  export:      boolean    // 个人数据导出是否开放
}
```

前端**不得**在本地硬编码开启这些能力；读取失败时按"关闭"处理（fail-closed）。

## 1.7 G0 上线前阻断项（非工程任务，但影响交付）

1. 小程序注册主体、AppID、服务类目与 UGC/视频能力核验；备案与运营责任人。
2. 内容安全服务（文本/图片/视频）开通与配额；审核值守人员与升级路径。
3. 隐私保护指引：处理目的、范围、保存期限、权利申请渠道、联系人。
4. 原型占位素材（来源 PDF 第 5、7 页照片与 4 秒样片）替换或取得授权。

**未完成 G0 前**：`capabilities.publicScope` 与 `capabilities.video` 保持关闭，仅做内部试点。

## 1.8 术语表（代码与文案统一用词）

| 术语 | 代码标识 | UI 文案 | 禁止写法 |
|---|---|---|---|
| 可见范围 | `visibility` | 谁可以看见 | 权限、隐私级别 |
| 公开 | `public` | 公开可见 | 全网公开、所有人 |
| 社内 | `club` | 仅社内可见 | 内部、私有 |
| 仅自己 | `private` | 只有自己可见 | 加密、保险箱 |
| 身份模式 | `identityMode` | 以树洞身份发布 | 匿名模式、隐身 |
| 匿名别名 | `alias` | 树洞旅人 NN | 马甲、小号 |
| 共鸣 | `reaction` | 共鸣 | 点赞、赞 |
| 收藏 | `bookmark` | 收藏 | 珍藏、mark |
| 碎片 | `fragment` | 碎片 | 动态、短帖 |
| 文章 | `article` | 文章 | 长文（正文可用"长文阅读"） |
| 待审核 | `pending` | 已收到，等待审核 | 发布成功 |
| 退回 | `rejected` | 需要修改 | 违规、封禁 |
| 文集 | `collection` | 文集 | 专栏、合集 |

## 1.9 北极星与关键指标（埋点需求）

- 北极星：**每周完成"表达—得到实质回应"的独立成员数**。
- 需要的埋点（不含正文内容、不含匿名映射）：发布提交/成功/失败原因、首次回应时延、
  范围选择分布、匿名使用率、草稿恢复率、搜索空结果率、上传失败率。
- 埋点**禁止**记录：正文、草稿内容、匿名 alias 与 userId 的关联、搜索原始词的长期明文留存。
